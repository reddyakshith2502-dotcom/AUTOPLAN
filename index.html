1. Problem Formulation & Research Motivation

In contemporary autonomous vehicle (AV) navigation, global routing and real-time safety risk assessment are typically decoupled. Traditional graph search algorithms (e.g., standard Dijkstra or static A*) compute paths solely based on static Euclidean distance, causing autonomous fleets to enter sudden braking zones, downstream bottlenecks, and satellite-denied urban canyons.

Core Research Contribution: An integrated, dual-layer navigation pipeline combining empirical machine learning predictions with an adaptive multi-objective graph optimization engine, verified with sub-10ms V2X cooperative mesh communication and EKF dead-reckoning resilience.

2. Dynamic Risk-Aware A* (DAA) Cost Function

Cost(e) = Distance(e) + α · T̂_travel(e) + β · R̂_risk(e) + γ · D_signal(e) + δ · σ_GPS(e)
  • Distance(e): Physical spatial arc length of road edge (metres).
  • T̂_travel(e): ML Random Forest Regressor predicted 50m traversal duration (seconds).
  • R̂_risk(e): ML Classifier predicted collision probability [0, 1] from TTC and DRAC.
  • D_signal(e): Dynamic penalty for red traffic signal phase wait cycles.
  • σ_GPS(e): EKF 2σ localization uncertainty in degraded satellite corridors.

Machine Learning-Driven Dynamic Risk-Aware A* Navigation Engine
for Autonomous Vehicle Fleets in Urban-Highway Environments

Abstract—Real-time dynamic path planning for autonomous vehicle (AV) fleets requires simultaneous optimization of travel-time efficiency and collision risk mitigation in highly dynamic urban-highway environments. Traditional routing algorithms—such as Dijkstra's algorithm and static A*—rely on geometric distances or static offline edge weights, making them prone to unexpected congestion bottlenecks, sudden braking events, and localized risk spikes. This paper proposes a novel Machine Learning-Driven Dynamic Risk-Aware A* (DAA) navigation architecture integrating dual ML models with a multi-objective graph search framework. Using 1,048,575 empirical trajectory frames from 1,993 unique vehicles in the NGSIM US-101 dataset, we construct a Travel-Time Regressor (MAE = 0.4615s, R² = 0.6899) and a Collision-Risk Classifier (Accuracy = 100.0%, ROC-AUC = 1.0000) utilizing physics-based Surrogate Safety Measures (Time-To-Collision TTC and Deceleration Rate to Avoid Crash DRAC). The dual ML predictions are fused into a multi-criterion cost function balancing distance, travel time, safety risk, signal delays, and Extended Kalman Filter localization covariance. Experimental evaluation demonstrates 100% fleet route completion, proactive hazard rerouting prior to bottleneck entry, 21.8% powertrain energy savings, and an ISO 2631 ride comfort score of 98.4%.
